# Botanical Atelier — Bodhiva Global Website Demonstration

A **fictional, independent portfolio concept** demonstrating a responsive four-page botanical studio website. This is not a website commissioned by Plant Art or any other client.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `selected-work.html` — Selected Work

## Preview
Open `index.html` in a browser. No build tools required.

## Cloudflare Pages deployment
Connect this repository to Cloudflare Pages as a static site. Use `main` branch, **no build command**, and `/` as the output directory (or use direct upload of the contents). Do not alter client DNS or email records for this demonstration.

## Contact form
The form is intentionally **demo-only** and does not transmit messages. For a real project, create a Formspree form owned by the client, replace the demo handler with an HTTPS POST to the client's Formspree endpoint, add appropriate privacy disclosures, and test end-to-end.

## Imagery and ownership
Images are loaded from Unsplash URLs for illustration only and are not part of the repository. Confirm usage rights and replace with appropriately licensed/client-owned images before commercial delivery. Source code and fictional text created for the demonstration. Do not represent concept imagery as completed client work.

## Notes
Mobile navigation, accessible labels, descriptive alt text, SEO descriptions, and a responsive layout are included. Production projects require accessibility, performance, security, SEO and browser testing.
